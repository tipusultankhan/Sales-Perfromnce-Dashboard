# Sales Performance Dashboard | Excel Project

## Overview

Developed an interactive Sales Performance Dashboard in Microsoft Excel to analyze sales data and business performance. The dashboard presents key metrics and trends to support data-driven business decisions.

## Key Features

- Used Pivot Tables, Pivot Charts, Slicers, and Excel formulas to track key performance indicators (KPIs).
- Analyzed total sales, revenue, profit, regional performance, and product-wise sales trends.
- Created visual reports to identify sales patterns and support business decision-making.

## Skills and Tools

MS Excel, Pivot Tables, Pivot Charts, Slicers, Data Analysis, Dashboard Reporting.
